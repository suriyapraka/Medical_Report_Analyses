# Medical Report Data Analysis

## About Me

I am Suriya Prakash, an aspiring Data Analyst passionate about exploring medical data, identifying patterns, and transforming raw data into meaningful insights.

## Project Overview

This project focuses on analyzing medical report data to understand patient health indicators, including age, BMI, blood pressure, glucose, insulin, cholesterol, physical activity, and progression scores.

## Dataset Columns

- Age
- BMI
- Blood_Pressure
- Glucose
- Insulin
- Cholesterol
- Physical_Activity
- Progression_Score

## Project Objectives

- Perform data cleaning and preprocessing.
- Analyze patient health indicators.
- Calculate descriptive statistics.
- Identify patterns and relationships between variables.
- Create meaningful visualizations.
- Present insights using data analysis tools.

## Tools & Technologies

- Microsoft Excel
- SQL
- Python
- Pandas
- NumPy
- Power BI

## Expected Outcomes

- Clean and structured medical data.
- Statistical summaries of health indicators.
- Visualizations and analytical insights.
- An interactive dashboard or analytical report.

## Disclaimer

This project is for educational and data analysis purposes only. It does not provide medical diagnoses or replace professional medical advice.
